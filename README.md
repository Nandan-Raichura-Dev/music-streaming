# Spotify Clone

A Spotify-inspired UI clone built using HTML, CSS, and JavaScript. This project is mainly focused on the front-end design, while JavaScript is used only for a few basic functionalities.

## Live Link



## Features

- Clean and modern Spotify-like interface
- Built with HTML, CSS, and JavaScript
- UI-focused project
- Basic interactive elements using JavaScript
- Simple and responsive layout

## Tech Stack

- HTML5
- CSS3
- JavaScript

## About the Project

This project was created to practice front-end development by recreating the look and feel of Spotify. The main focus was on designing the user interface and improving styling skills rather than adding complex functionality.

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Run `index.html` in your browser.
